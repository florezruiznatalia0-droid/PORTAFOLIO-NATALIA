# Portafolio de Natalia Florez

Archivos: `index.html` (estructura), `style.css` (diseño y animaciones), `script.js` (interacciones) e `images/` (fotos).

## Abrirlo en Visual Studio Code
1. Abre la carpeta `portafolio-natalia` en VS Code (Archivo > Abrir carpeta).
2. Instala la extensión **Live Server** y haz clic en "Go Live" para verlo en el navegador.

## Subirlo a GitHub y publicarlo
1. Crea un repositorio nuevo en github.com (por ejemplo `portafolio`).
2. Sube todos los archivos y la carpeta `images` (botón "Add file > Upload files").
3. Ve a **Settings > Pages**, elige la rama `main` y la carpeta `/ (root)`, y guarda.
4. En un par de minutos tendrás un enlace público.

## Cambiar textos y fotos
- Textos: edita `index.html` (y las tarjetas de las carpetas en la lista `F` de `script.js`).
- Fotos: reemplaza los archivos de `images/` conservando el nombre.
- Colores: variables al inicio de `style.css` (`--bl`, `--dp`).
